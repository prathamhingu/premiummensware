# Render Free Private Preview — Deployment Checklist

## Before GitHub
- [ ] Extract this package into a new folder; do not overwrite the original local project.
- [ ] Node.js 20+ / 22 installed.
- [ ] `npm --prefix backend ci` succeeds.
- [ ] `npm --prefix backend run check` succeeds.
- [ ] `npm --prefix backend test` succeeds.
- [ ] Business details meant to appear in the preview are configured in `backend/data/seed-site-data.json`.
- [ ] `backend/.env` is local-only and is not committed.
- [ ] Repository is private; staged files contain no real admin/customer JSON, sessions, uploads, secrets, hashes or backups.

## Secrets prepared locally
- [ ] Run `npm --prefix backend run preview:hash`; save `PREVIEW_PASSWORD_HASH` privately.
- [ ] Run `npm --prefix backend run admin:bootstrap-hash`; save `INITIAL_ADMIN_USERNAME` and `INITIAL_ADMIN_BCRYPT_HASH` privately.
- [ ] Preview password and administrator password are different.
- [ ] No passwords or generated hashes have been committed.

## Render configuration
- [ ] Connect the private repository as a Render Blueprint and set Blueprint Path to `deployment/render.yaml`.
- [ ] The service plan is **Free**.
- [ ] No persistent disk or paid database has been added.
- [ ] `PREVIEW_GATE_ENABLED=true`.
- [ ] `PREVIEW_PASSWORD_HASH` set to the generated scrypt hash.
- [ ] `SESSION_SECRET` generated by Render.
- [ ] `INITIAL_ADMIN_USERNAME` and `INITIAL_ADMIN_BCRYPT_HASH` set. Keep these in Render Environment settings on Free.
- [ ] `ALLOW_PUBLIC_PRODUCTION` is unset or false.

## Post-deployment verification
- [ ] Open the actual Render HTTPS URL in a private/incognito browser.
- [ ] Incorrect preview password is rejected.
- [ ] Correct preview password opens the website.
- [ ] Direct page, asset, uploaded-image and content/API routes do not bypass the gate.
- [ ] `/healthz` returns only `ok`.
- [ ] Preview password does not grant admin access.
- [ ] Administrator login works separately.
- [ ] Verify public business details and supplied product imagery.
- [ ] Remember: Render Free can lose all locally stored edits/uploads and sessions on spin-down, restart, or redeploy.
- [ ] Share the URL and raw preview password separately with invited viewers.

## If anything fails
- [ ] Review Render build/runtime logs.
- [ ] Do not disable the preview gate as a workaround.
- [ ] Never disclose `.env`, password hashes, session secrets, or real customer records.
